# AGENTS.md

This file provides guidance to agents when working with code in this repository.

## Build/Test/Lint Commands

- `make setup` - Set up dev environment (requires `uv` tool)
- `make all` - Full regression: lint + unit tests + build + integration tests
- `make test-unit PYTEST_ARGS='-k dedup'` - Run filtered unit tests
- `make test-unit PYTEST_ARGS='tests/unit/test_backup_tables.py::test_name'` - Run single test
- `make test-integration BEHAVE_ARGS='-i ssl_support'` - Run filtered integration tests (behave BDD)
- `make start-test-env` / `stop-test-env` / `clean-test-env` - Docker test environment (ClickHouse + Minio)
- `CLICKHOUSE_VERSION` - Env var to set ClickHouse version for integration tests

## Code Style (Non-Obvious)

- **Logging**: Use `from ch_backup import logging` module, NOT direct `loguru` calls. Format: `logging.debug("msg {} {}", arg1, arg2)`
- **Exceptions**: Base class is `ClickhouseBackupError`; wrap lower-level exceptions with `from e`
- **Imports**: `isort` with black profile; no top-level imports inside functions (except conditional for type hints)
- **Types**: Python 3.10+; `mypy` enforces `disallow_incomplete_defs`, `check_untyped_defs`, `implicit_optional`
- **Security checks disabled** in tests (`tests/**` in ruff config); `assert`, `shell=True`, `md5` allowed in source

## Architecture

- **Entry point**: [`cli()`](ch_backup/cli.py:119) - ClickHouse backup CLI using `cloup` (Click + options)
- **Main logic**: [`ClickhouseBackup`](ch_backup/ch_backup.py:51) class in [`ch_backup.py`](ch_backup/ch_backup.py)
- **Config**: [`Config`](ch_backup/config.py:256) loads YAML; nested dicts merged recursively; defaults in [`DEFAULT_CONFIG`](ch_backup/config.py:18)
- **Async pipelines**: Storage uploads/downloads use `pypeln` async pipelines
- **Backup managers**: Access, Database, Table, UDF, NamedCollections in [`ch_backup/logic/`](ch_backup/logic/)

## Testing Patterns

- **Unit tests**: `tests/unit/` with pytest; `@pytest.mark.parametrize`; mocks with `unittest.mock`
- **Integration tests**: `tests/integration/` with behave BDD framework (Gherkin `.feature` files)
- **Test step definitions**: [`tests/integration/steps/`](tests/integration/steps/) - `given/when/then` decorators
- **Test modules**: [`tests/integration/modules/`](tests/integration/modules/) - Docker, ClickHouse, Minio, ZooKeeper helpers

## Critical Gotchas

- Version file [`ch_backup/version.txt`](ch_backup/version.txt) is auto-generated by `make setup` (git-based)
- Integration tests require Docker Compose; session file `.session_conf.sav` tracks test env state
- Logs go to `/var/log/ch-backup` by default; configured in [`loguru`](ch_backup/config.py:194) section
- ZooKeeper flock for distributed locking; `lock.zk_flock` must be enabled for multi-node setups
